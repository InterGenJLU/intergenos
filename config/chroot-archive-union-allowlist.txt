# chroot-archive-union allowlist — files legitimately present in the built
# chroot that NO sealed archive should ever carry. Consumed by
# scripts/check-chroot-archive-union.py (build pre-flight gate).
#
# Format: <pattern><TAB or 2+ spaces><reason>. Three pattern forms:
# exact path, `dir/**` subtree prefix, fnmatch glob. An entry without a
# reason refuses the gate (same engine as the Step 4.85 allowlist).
#
# Discipline: this list holds STRUCTURAL classes only — state a mechanism,
# not a package. Per-finding additions from real firings carry a date in
# the reason. Seeded 2026-08-19 with the structurally-certain classes; the
# first real firing against a build substrate dispositions the remainder
# per-finding (the same way the Step 4.85 allowlist was built).

var/lib/igos/**	the package system's own state (pkm.db, sealed archives, text manifests, helpers, integrity logs) — by definition not archive payload
var/log/**	runtime logs written during the build; never archive-carried
etc/ld.so.cache	ldconfig-generated linker cache
etc/ld.so.cache~	ldconfig temp twin
usr/lib/locale/locale-archive	localedef-generated locale archive
etc/ssl/certs/**	ca-certificates rehash-generated symlink farm and bundle state
etc/systemd/system/*.wants/**	systemctl preset/enable-generated unit symlink farm
etc/systemd/system/*.requires/**	systemctl enable-generated unit symlink farm
etc/passwd-	shadow-suite backup twin (pwconv/useradd-generated)
etc/group-	shadow-suite backup twin (grpconv/groupadd-generated)
etc/shadow-	shadow-suite backup twin
etc/gshadow-	shadow-suite backup twin
etc/subuid-	shadow-suite backup twin
etc/subgid-	shadow-suite backup twin
root/**	build-user home state (caches, histories); squashfs Step 3 purges it and it never ships or installs
home/**	build-user homes; outside the shipping/install tree
usr/lib/python*/site-packages/**/__pycache__/**	interpreter-generated bytecode caches (unmatched ones are post-seal regeneration)
var/lib/systemd/**	systemd machine-generated state (journal catalog, timers, random-seed)
