# Kernel symbols this distribution requires at an EXACT value.

# Read by scripts/check-kernel-required-symbols.py, which both kernel recipes run
# after merging the config fragments. Each line is the literal line that must be
# present in the produced .config, so the value is part of the requirement: for
# these symbols built-in-ness IS the guarantee, and =m would be a silent
# downgrade rather than a packaging choice.
#
# WHY THIS EXISTS. `cat fragments/*.config | olddefconfig` has no conflict
# detection. A dependency downgrade — DM_VERITY=y quietly demoted to =m because
# its BLK_DEV_DM dependency was =m — or a fragment-ordering regression can strip
# a security guarantee while the build still succeeds. Asserting the PRODUCED
# config and hard-failing on drift is what turns that into a build failure.
#
# The list moved out of the recipes and into this file on 2026-08-11, when the
# same assertions had to apply to BOTH kernel passes. Two copies of a 28-symbol
# list in two shell scripts is a drift class waiting to happen; one file read by
# both is not. Origin of the assertions: audit D-1, 2026-05-29.
#
# Format: one literal CONFIG_X=value line per entry. Comments and blank lines
# are ignored.
