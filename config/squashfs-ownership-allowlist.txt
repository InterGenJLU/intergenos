# squashfs ownership-gate allowlist (consumed by scripts/check-squashfs-ownership.py)
#
# Every file in the shipping tree must be traceable to an installed package's
# manifest. This file is the ONLY sanctioned exception surface: each entry is
# a pattern plus a mandatory reason, reviewed in-tree. Anything on disk that
# matches neither a manifest nor an entry here FAILS the squashfs build.
#
# Format: <pattern><TAB or 2+ spaces><reason>
#   pattern forms:  exact relative path      etc/fstab
#                   subtree                  usr/share/mime/**
#                   glob (fnmatch)           usr/share/icons/*/icon-theme.cache
# Lines starting with # and blank lines are ignored. A malformed line
# (no reason column) fails the gate — an exception without a why is not
# reviewable.
#
# Classes below marked DEBT(<tracker-row>) are acknowledged pre-existing gaps
# (shipped in every prior ISO) owed a real per-recipe fix — they are listed so
# the gate can hold fail-closed against NEW classes while the debt is worked.
# Decided 2026-07-22 (ownership survey of the full chroot; F41 wave).
